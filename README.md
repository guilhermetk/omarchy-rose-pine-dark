# Rose Pine Dark theme for Omarchy

A dark ([Rosé Pine Main](https://rosepinetheme.com/)) theme for [Omarchy](https://omarchy.org/).

Note: Omarchy Quattro ships a built-in `Rose Pine` theme, which is the light
**Dawn** variant. This repo is the dark **Main** variant and installs as
`rose-pine-dark`, so the two can coexist.

## Installation

```bash
omarchy theme install https://github.com/guilhermetk/omarchy-rose-pine-dark
```

Note: themes installed from a git repo only apply colors — `neovim.lua` and
`vscode.json` are skipped by Omarchy and regenerated from `colors.toml`, so
the editor falls back to the generated theme until you copy those files
manually.
